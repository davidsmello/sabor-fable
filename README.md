# Sabor Fable

Skill para Claude Code com o guia de design visual do Grupo PTG (PYCloud, Paraguay Tech Group e divisões).

Ela foi destilada dos trabalhos de design que o Fable 5.2 fez e que foram aprovados: o site da PYCloud ("ficha técnica cartográfica"), o PY Console e o site do grupo. A ideia é que qualquer modelo, como o Opus, repita esse resultado seguindo as mesmas decisões e o mesmo processo.

## O que tem

- `SKILL.md`: processo (propor em tabela antes de mudar, medir antes e depois, conferir os dois temas e o celular, uma PR por rodada, não inventar dados) e as regras de design que não mudam sem pedido.
- `references/linguagem-visual.md`: tokens de cor dos temas escuro e claro, tipografia, grid, componentes, ícones e o mapa animado.
- `references/historico-decisoes.md`: o que foi aprovado, rejeitado e corrigido em cada projeto.

## Instalação

```bash
git clone https://github.com/davidsmello/sabor-fable.git ~/.claude/skills/sabor-fable
```

Depois, chame com `/sabor-fable` ou peça algo como "sabor fable", "no estilo do Fable" ou "deixa igual ao site da PYCloud".
